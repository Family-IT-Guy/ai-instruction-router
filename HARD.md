# HARD facts

The list of facts that must fire unprompted: traps in a named tool, vendor, service or system where the obvious reading is wrong and acting on it has already cost something. Every session, any folder.

A row fires when its name is in the work. Each row has four columns:

- **Name** is the word that will be present when the trap is near: the vendor, tool or system as it appears in commands, files and conversation.
- **Slug** names the companion file `~/.agent/how/vendors/<slug>.md`, which holds the commands and the story of the incident. It is written in the same turn as the row. Open it when the row fires and the work needs more than the row says.
- **Do** is the action that avoids the trap, short enough to act on without opening the companion file.
- **Wrong reading** is the conclusion that already happened once, with its date and what it cost. It is what makes the row binding: a session treats a trap as real when it can see that the trap was sprung.

A row comes from a trap that was sprung, which is what its Wrong reading column records. Removing a row follows `~/.agent/when/self-change.md`.
